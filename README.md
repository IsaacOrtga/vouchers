# vouchers
Application for creating and redeeming vouchers


# Project Dependencies

This project relies on the following key dependencies for its functionality and development:

---

## `react-router-dom`

* **Purpose (English):** Essential for **client-side routing** in your React application. It allows different URLs to display distinct components without full page reloads, creating a smooth single-page application (SPA) user experience.
* **Propósito (Español):** Esencial para la **navegación del lado del cliente** en tu aplicación React. Permite que diferentes URLs muestren distintos componentes sin recargar la página, creando una experiencia de usuario fluida (Single-Page Application).

---

## `localforage`

* **Purpose (English):** A utility for **offline data storage** in the browser. It simplifies caching data fetched from APIs, improving performance and enabling offline capabilities, especially useful with React Router's data loading features.
* **Propósito (Español):** Utilidad para el **almacenamiento de datos offline** en el navegador. Facilita el caching de información obtenida de APIs, mejorando el rendimiento y la capacidad de la aplicación para funcionar sin conexión, especialmente útil con las funciones de carga de datos de React Router.

---

## `match-sorter`

* **Purpose (English):** An efficient library for **filtering and sorting lists of objects** based on text string matching. It's ideal for implementing dynamic search and filtering results, often used in conjunction with React Router's URL parameters.
* **Propósito (Español):** Una biblioteca eficiente para **filtrar y ordenar listas de objetos** basándose en la coincidencia de texto. Ideal para implementar búsquedas dinámicas y filtrar resultados, a menudo utilizada junto con los parámetros de URL de React Router.

---

## `sort-by`

* **Purpose (English):** A lightweight tool for **sorting collections of objects** by one or more properties. It complements data management, allowing API data to be presented in a specific order, which can be controlled via URL query parameters.
* **Propósito (Español):** Una herramienta ligera para **ordenar colecciones de objetos** por una o más propiedades. Complementa la gestión de datos, permitiendo presentar información de APIs en un orden específico, lo que puede controlarse a través de los parámetros de consulta de la URL.
